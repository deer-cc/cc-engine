# 物流规则

## 发货时效

| 下单时间 | 发货时间 |
|:---------|:---------|
| 工作日 0:00-20:00 | 当天 |
| 工作日 20:00-24:00 | 次日 |
| 周末/节假日 | 下一个工作日 |

## 快递时效

| 地区 | 预计到达 |
|:-----|:---------|
| 江浙沪皖 | 1-2天 |
| 华北/华南/华中 | 2-4天 |
| 西南/西北 | 3-5天 |
| 新疆/西藏 | 5-7天 |

## 运费标准

- 订单满 **99元** → 包邮
- 订单不满99元 → 运费 **10元**
- 大件商品（>20kg）→ 运费按实际计算
