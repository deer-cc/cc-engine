# 退换货规则

## 七天无理由退货

- 支持 **7天无理由退货**（自签收之日起算）
- 商品需保持 **原包装完整**，不影响二次销售
- 退货运费：**买家承担**（质量问题除外）

## 质量问题退货

- 商品存在质量问题 → **全额退款 + 承担运费**
- 需提供 **照片/视频证据**
- 客服审核通过后寄回商品

## 换货流程

1. 联系客服说明换货原因
2. 确认换货商品信息
3. 寄回原商品
4. 收到退货后发出新商品

## 不适用无理由退货的商品

以下商品不支持七天无理由退货：
- 定制类商品
- 贴身衣物
- 数字化商品（激活后）
- 保质期有限的商品

## 退款时效

- 仓库签收退货后 **1-3个工作日** 内退款
- 退款原路返回（支付宝/微信/银行卡）

## 退货运费险

订单金额满 **199元** 自动赠送退货运费险，退货时可直接抵扣运费。
